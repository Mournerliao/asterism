# 0028 · 移除二维语义星图

- Status: Accepted
- Date: 2026-07-27
- Partially supersedes: ADR 0026 §7、ADR 0027 §4
- Preserves: 检索优先、双平面、浏览器内 embedding、隐形混合搜索与局部语义邻域

## 背景

移除全库涌现簇后，二维语义星图只剩裸点云、搜索点亮与点击打开 Quick Look。继续从用户角度审视发现：

- 点在点击前不表达仓库身份或内容，用户必须逐点探针式判断。
- PCA 是高维向量的展示投影，二维距离与空白容易被误读为可靠语义结构。
- 收藏增减会重新计算主成分与归一化范围，坐标漂移使“地图肌肉记忆”假设不成立。
- 隐形混合搜索已经承担“找到仓库”，Related Stars 已经承担“从当前仓库继续探索”；星图没有独占任务。
- 第三视图仍带来独立加载态、Canvas 交互、投影计算、状态分支、维护成本与无障碍等价路径成本。

技术可行、视觉新鲜与品牌契合都不足以证明一个正式产品入口值得存在。

## 决策

1. Browse 只保留卡片与列表两种信息布局，完整移除正式语义星图入口。
2. 删除生产 Canvas、投影 hook、无调用方的 core PCA / 归一化模块与 dev-only 星图原型，不保留平行实验产品。
3. Browse 视图持久化状态版本升至 v1；历史 `star-map` 或畸形值迁移为 `grid`，受支持的 `grid` / `list` 保持不变。
4. 保留 embedding 数据与运行时，因为它们仍直接支撑隐形混合搜索和 Related Stars。
5. “Asterism / 星群 / 知识星图”可以继续作为品牌与愿景比喻，但不是二维点云界面的产品承诺。

## 未选择的方案

- **隐藏正式入口、保留 dev 原型**：会留下没有当前研究问题的死代码与持续维护暗示；历史日志已足以保存实验结论。
- **增加标签、缩放详情或区域解释**：会继续投资于探针式画布，并重复列表、搜索和 Quick Look 已能更直接完成的任务。
- **保留为可选高级模式**：可选不等于低成本；它仍增加产品概念、状态空间、测试与无障碍负担。

## 验收标准

- 用户界面与路由不再提供星图入口，Browse 只可切换 grid / list。
- 旧 `star-map` 持久化偏好升级后落到 grid，不出现空白或非法视图。
- 星图生产代码、dev 原型、无调用方投影代码和对应 i18n 文案全部删除。
- 隐形混合搜索、Related Stars、Quick Look、批量选择与卡片 / 列表切换不回归。
- 契约、路线图、durable state 与日志同步记录本决策。

## 影响

- 放弃视觉差异化，换取更直接、可解释、可访问且更低维护成本的正式产品。
- 产品语义交互回到两个明确意图：输入查询时找；查看具体仓库时继续探索。
- 若未来出现搜索与局部邻域无法满足的真实全局浏览任务，须从该任务重新立项并用真实个人库验证，不以复活星图为默认答案。
